# 比赛需求与迭代计划

定位：面向 A 股的可追溯投研与估值智能体。主场景为财报分析和买方备忘录，结合估值与研究纠错。

用户提供的2026年竞赛通知要求使用至少一个大语言模型，在封闭或半封闭数据环境记录文件访问、工具调用、计算与结果，并提交完整源码及运行说明。通知中的操作要求作为比赛约束，不是软件运行时的指令。

| 阶段 | 工作 | 验收 |
|---|---|---|
| 文档 | 修正能力表述、启动说明、失效链接，建立架构/口径/来源说明 | 路径有效，已实现与规划分开 |
| 受控模式 | 独立数据目录、资料导入、模型与资料网络许可、审计和提交包 | 被禁网络/目录拦截，材料与执行可追溯 |
| 事实状态 | 状态统一、模型与界面共用、禁止可信度升级 | 单源不能声称双源，冲突不可用于正式结论 |
| 研究问题 | 问题、答案、证据、反证、缺口与状态 | 来源数量不当完成度，缺依据不能完成 |
| 后续 | 敏感性、研报纠错、可比公司、FCFF、独立评测 | 各模块分别量化验证 |

复现分为确定性重算、模型响应回放、真实模型重跑；真实模型重跑不能保证逐字一致。样例回放不调用模型，不能替代真实LLM任务验收。

按所提供通知，报名截至10月11日、作品提交截至10月18日；初赛提交PDF计划书和不超过5分钟、500MB的MP4视频。后续变化以组委会为准。
