# 问题级证据清单

页面“问题与证据”展示每个问题的完成条件、答案、支持/反方原文、缺口、下一步及历史。默认研究问题为待处理；追加问题不覆盖既有答案。

状态包括待处理、部分回答、有证据回答（待复核）、证据冲突、无法验证。完成统计来自问题状态，不来自搜索次数、正文数量或报告保存成功。

Agent可调用 `plan_research_questions` 和 `update_research_question`；深度研究的规划阶段形成细分问题，成稿阶段返回 `question_answers`，在保存报告时原子保存答案与对应原文。

每个binding保存真实来源ID、连续原文摘录、支持/反方关系、关系解释、日期、定位和来源内容哈希。程序检查来源存在、摘录真实匹配、截止日、摘要/OCR状态、关联财务冲突。只引用摘要、缺日期、缺答案、缺反方说明或仍有缺口时不能标为有证据回答；新增资料本身也不会自动完成问题。

**边界：摘录匹配只能证明取到并引用该文字，不能自动证明它在语义上充分支持答案。** 支持关系由模型或人工判断并保留来源标记，界面明确“待复核”；并不声称完成了通用因果或投资判断验证。

来源变化会使清单读视图降为部分回答，历史原记录不自动覆盖。答案修改保留旧版；重复相同更新不新增历史。人工记录只更新问题，不自动改写报告。当前稿和审计稿导出也包含问题清单。

API：

- GET `/api/runs/{id}/questions`：清单和状态统计。
- GET `/api/runs/{id}/question-sources`：实际来源的有界摘录。
- POST `/api/runs/{id}/questions`：`{"questions":[{"question":"具体问题","completion_criteria":"所需证据"}]}`。
- POST `/api/runs/{id}/question-answers`：`{"answers":[{"question_id":"q-...","answer":"...","status":"partial","bindings":[],"gaps":["..."],"counter_evidence":"...","next_action":"..."}]}`。

以上修改不允许在正在执行的研究上通过页面/API操作；Agent自身按执行日志保存。明确只读或禁止保存的对话不能写问题记录。搜索到上限或资料联网禁止后，重复相同尝试会提前收束，保留已有结果及缺口。
